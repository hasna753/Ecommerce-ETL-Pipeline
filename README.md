# Ecommerce-ETL-Pipeline

## 📌 Project Overview
This project builds an **ETL pipeline** to analyze global e-commerce sales data.  
It demonstrates beginner-friendly **data engineering workflows** using Python, Pandas, SQLite, and SQL queries.

## ⚙️ Workflow
1. **Extract**: Load dataset from Kaggle (`Global E-Commerce Sales & Customer`).  
2. **Transform**: Clean data (remove nulls, duplicates, convert datatypes).  
3. **Load**: Store cleaned data into SQLite database.  
4. **Analyze**: Run SQL queries for insights:
   - Top countries by sales  
   - Top customers  
   - Monthly revenue trends  
   - Profit by region  

## 📊 Visualizations
- Line chart: Monthly sales trend  
- Bar chart: Top countries by revenue  
- Region-wise profit distribution  

## 🛠️ Tools & Skills
- Python (Pandas, Matplotlib, SQLite3)  
- SQL (aggregation, grouping, joins)  
- Kaggle Notebook environment  
- GitHub for portfolio presentation  

## 🚀 Key Insights
- Identified top-performing countries and customers.  
- Revealed monthly revenue trends for business forecasting.  
- Highlighted regional profitability for strategic decisions.
